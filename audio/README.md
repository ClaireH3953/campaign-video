# Audio 資料夾

此資料夾用於存放語音旁白檔案。

## 需要的檔案

請將以下10個MP3語音檔案放入此資料夾：

1. `voice_scene1.mp3` - 開場
2. `voice_scene2.mp3` - 第一代
3. `voice_scene3.mp3` - 第一代的堅持
4. `voice_scene4.mp3` - 第二代接棒
5. `voice_scene5.mp3` - 傳承的溫度
6. `voice_scene6.mp3` - 傳承交棒
7. `voice_scene7.mp3` - 第三代延續
8. `voice_scene8.mp3` - 颱風實戰（重點）
9. `voice_scene9.mp3` - 用心服務
10. `voice_scene10.mp3` - 結尾

## 快速生成

在專案根目錄執行：
- Windows: 雙擊 `generate_voice.bat`
- Mac/Linux: `python3 generate_voice.py`

## 線上生成

使用線上工具：https://tts.travisgeis.com/
選擇語音：zh-TW-HsiaoChenNeural（女聲）

詳細說明請參考專案根目錄的 `VOICE_QUICKSTART.md`
